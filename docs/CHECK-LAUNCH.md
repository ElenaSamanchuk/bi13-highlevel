# Проверка запуска 16.11.2026 без ИИ

Скрипт `scripts/check-launch.mjs` (Node, без зависимостей; рендер через Playwright из `node_modules` проекта, при несовпадении версии берёт любой Chromium из `~/Library/Caches/ms-playwright`). Только чтение: GET-запросы и открытие страниц в headless-браузере.

## Команды

    node scripts/check-launch.mjs                                   # сейчас
    node scripts/check-launch.mjs --at "2026-11-16T10:05:00+03:00"  # подмена времени (ожидание и часы в браузере)
    node scripts/check-launch.mjs --sales=open                      # ?sales= на GitHub Pages
    node scripts/check-launch.mjs --no-browser --timeout=40000

Код выхода: 0 нет ❌ (⚠️ допустимы), 1 есть ❌. Вывод построчно ✅/⚠️/❌ и итог.

## Что покрывает

- BI13 (`bi13pro.ru/aesthetic-high-level`, GitHub Pages): наличие кода таймера (OPEN_MS=1794812400000, CLOSE_MS=1796072400000), ожидаемый вид по времени (до 16.11 10:00 МСК before, до 01.12 00:00 open, дальше after), `#page-root[data-sales]`, видимых `a[data-pay]` 4 в open и 0 иначе, адреса кнопок.
- 4 страницы оплаты отвечают 200 (до 3 попыток по 40 с), все `lk.bi13pro.ru/payments/…/checkout` с них отвечают 200.
- `#page-root` (одноблочная версия, GitHub Pages) или оба корня `.bi13p` (код в два блока Тильды): у каждого корня нужный `data-sales`.
- Таплинк Kinezio здесь больше не проверяется (13.11 сменились канал и шапка): отдельный скрипт `cd ~/Projects/kinezio-taplink && node scripts/check-launch.mjs`.

## Ограничения

- Пока Елена не вставила код на боевую Тильду, для боевых адресов выводится ⚠️ «код не найден» (это не ошибка). Рендер боевой страницы проверяется только если код найден в HTML; код в iframe на другом домене по HTML боевой страницы не видно.
- `--at` подменяет часы только в браузере и в ожидании; сервер и сами сайты время не знают. `--sales` применяется к GitHub Pages, не к боевым адресам.
- Боевые сайты иногда отвечают медленно или обрываются по таймауту (замечено 13.11 на payment-allway-oc и kineziofitness.online/taplink); повторы смягчают это, но сетевая проверка остаётся зависимой от доступности.
- Проверяется только страница оплаты и ссылка checkout (200), сама оплата и содержимое lk не проверяются. Telegram-ссылки только сверяются по href, не открываются.
- Общий смоук сайтов и визуальный дизайн скрипт не заменяет.
